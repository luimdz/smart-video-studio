Alcance vigente: herramienta de uso propio

La prioridad es una aplicación para el propietario, con UI local y servicios de producción. El 8 de noviembre de 2026 se recuperó acceso a n8n y quedó conectado por MCP: retomamos n8n para coordinar las etapas. La comercialización se evaluará posteriormente.

Funciones de esta etapa:

- Un usuario propietario con control de configuración y gasto.
- Perfiles independientes para separar páginas, canales y negocios de clientes cuyo contenido gestione el propietario.
- Videos individuales y temporadas completas de 10–25 capítulos, con personajes y continuidad persistentes.
- Micro VSL de 120–300 segundos.
- Producción prioritaria con 2D reutilizable e imágenes con movimiento.
- APIs para texto, voz e imágenes; coordinación con n8n y servicios propios para planificación, render y adaptadores audiovisuales.
- Cola persistente, seguimiento de etapas, recuperación y presupuesto por producción y perfil.
- Publicación automática en Facebook e Instagram; archivos y textos para programación manual en otras redes.

Un perfil de cliente en esta etapa es una ficha de negocio administrada por el propietario; no es una cuenta de acceso para ese cliente.

El portal externo de clientes, cobros, suscripciones, invitaciones y planes comerciales quedan aplazados. Las estructuras ya creadas de cuentas y planes se conservan como trabajo previo; no son una dependencia de la versión de uso propio y no deben recibir prioridad de desarrollo.

La UI, el planificador y las reglas existentes son reutilizables. El primer flujo de planificación ya está guardado como borrador desactivado en n8n, pero requiere configurar la dirección del servicio del estudio y sus credenciales. La adaptación de almacenamiento y acceso local sigue pendiente. n8n alojado necesita una vía autenticada para alcanzar cualquier servicio que se ejecute en este equipo; esa conectividad no está configurada.

Cuando el procesamiento y calendario sean locales, el equipo deberá permanecer encendido, sin suspensión y con el servicio activo para ejecutar trabajos; las llamadas API y publicaciones requieren internet. Publicar con el equipo apagado requeriría después un servicio alojado.

No se ha autorizado la subida del código ni el despliegue remoto por esta aclaración de alcance.
